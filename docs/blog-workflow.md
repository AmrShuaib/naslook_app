# مدونة ناس لايف: كيف تُضاف التحديثات والأخبار

الصفحة العامة: https://naslife.app/blog (وتعمل على www.naslife.app/blog أيضاً).

- القائمة: `/blog` مع مرشّح `?kind=update` أو `news` أو `post`.
- المنشور: `/blog/<slug>` بوسوم Open Graph لمعاينة الرابط في واتساب وإكس.
- الخلاصات: `/blog/feed.json` و`/blog/rss.xml`.

## محرر المدونة في لوحة الإدارة

من لوحة الإدارة (ماي سبيس → لوحة الإدارة، أو admin.naslife.app) افتح قسم **المدونة**:

- القائمة: عدّادات (الكل، منشور، مسودة، مجدول، مشاهدات)، بحث في العناوين والنصوص، ومرشّح النوع.
- لكل منشور قائمة إجراءات: تعديل، نشر الآن أو إلغاء النشر، جدولة النشر بتاريخ ووقت، معاينة على الموقع (رابط مؤقت للمسودات صالح 24 ساعة)، تثبيت في الأعلى، نسخ الرابط، نسخ كمسودة، حذف.
- المحرر: النوع، العنوان، الملخص، صورة الغلاف (رفع من الجهاز أو رابط)، النص بشريط التنسيق وزر إدراج صورة، معاينة بشكل الصفحة النهائية، وخيارات متقدمة (معرّف الرابط، الوسوم، التثبيت، تاريخ النشر).
- أزرار الحفظ: **نشر الآن**، **جدولة**، **مسودة**. المسودات لا تظهر للزوار حتى تُنشر.
- كل إجراء يُسجَّل في «سجل الإجراءات».

المنشورات محفوظة في قاعدة البيانات (جدول `blog_posts`)؛ ملف `server/blog_posts.js` هو البذرة الأولى فقط ولا يعيد كتابة ما عُدّل من اللوحة.

## طريقة إضافة منشور جديد من المحادثة

أرسل في المحادثة أمراً بهذه الصيغة (أو ما يشبهها):

> أضف **تحديث** بعنوان «…» : النص …

> أضف **خبر** بعنوان «…» : النص …

> أضف **تدوينة** بعنوان «…» : النص …

النص يمكن أن يحتوي على التنسيق الخفيف نفسه المستخدم في منشورات التطبيق:

| تكتب | يظهر |
|---|---|
| `## عنوان` | عنوان فرعي |
| `- بند` | قائمة نقطية |
| `1. بند` | قائمة مرقّمة |
| `> نص` | اقتباس |
| `**نص**` | نص عريض |
| `[نص](https://…)` | رابط |
| `![وصف](https://…)` | صورة (رابط صورة مرفوعة) |
| `---` | فاصل |

وسأنشره لك من الواجهة نفسها (أو أضيفه إلى البذرة إن لم تكن قاعدة البيانات متاحة)، فيظهر على الموقع فوراً.

## بنية المنشور في الملف

```js
{
  slug: "ramadan-hours",        // معرّف الرابط: حروف لاتينية صغيرة وأرقام وشرطات
  kind: "news",                 // update | news | post
  date: "2026-09-14",           // تاريخ النشر
  order: 20,                    // ترتيب داخل اليوم نفسه (الأكبر يظهر أولاً)
  title: "ساعات العمل في رمضان",
  summary: "سطر واحد يظهر في القائمة وفي معاينة الرابط",
  body: `النص الكامل بالتنسيق الخفيف…`,
}
```

## ملاحظات

- الصور: الملفات في مجلدات فرعية لا تُنشر تلقائياً على الخادم، لذا استخدم رابط صورة مرفوعة على الموقع (مثلاً من رفع صورة في المحادثة) أو رابطاً خارجياً.
- لتعديل منشور منشور: عدّل نصه في الملف وادفع الفرع؛ الرابط يبقى ثابتاً ما دام `slug` ثابتاً.
- لحذف منشور: احذف كائنه من المصفوفة.
