# نماذج بروفايل المستخدم (سبتمبر 2026)

نماذج HTML تفاعلية بحجم الآيفون للنقاش مع المالك قبل البرمجة. الشخصية: فهد الغامدي، مصوّر في جدة.

- `template.html`: النموذج الأصلي بالعربية (أربع شاشات: الزائر، صاحب الحساب، تعديل الملف، التوثيق والتحكم).
- `template_en.html`: النسخة الإنجليزية.
- `template_colors.html`: يولّده `make_colors.py` من الأصل: ثماني لوحات ألوان بخلفية بيضاء دائماً (تتغيّر `--a` و`--a-soft` و`--a-ink` فقط) + «عرّف بنفسك» صوت حتى ٦٠ ثانية أو فيديو حتى ٣٠ ثانية.
- البناء: `python3 build.py template_colors.html > out.html` (يضمّن صور `img/` وأيقونات `icons.json`).

الروابط المنشورة: النموذج الأصلي والإنجليزي والألوان نُشرت كـ Artifacts خاصة في حساب المالك.
