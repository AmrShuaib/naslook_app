وترحيلات قاعدته `db/`، وأدوات تشغيله `ops/`، واختباراته `test/`. كل ما في `server/*.js` إضافات تعمل فوقه.

  حتى يكون المشروع كله في مستودع واحد. `README.upstream.md` هو README ذلك المستودع كما هو.

  النسخة العاملة في `/opt/naslife/src/index.js` على الخادم، وقد تختلف عن هذه إن عُدّلت هناك بعد 7 سبتمبر.
